### Autonomous DeFi Portfolio Agents

A trust-minimised portfolio management layer in which autonomous agents execute strategy on-chain through token-bound accounts, bridging off-chain AI inference with verifiable settlement inside Trusted Execution Environments to preserve custody guarantees end to end. Architected to eliminate the manual intervention that conventional portfolio tooling depends on, while maintaining a fully auditable execution trail across the off-chain and on-chain boundary. Recognised at Defy'26 as 2nd Runner-Up in the DeFi track.

An intelligent inbox platform engineered for high-precision semantic retrieval across large-scale, unstructured mail corpora. Built on RAG pipelines over Weaviate vector embeddings, with event-driven asynchronous orchestration through RabbitMQ and Gemini API integration for intent classification — enabling automated draft generation and multi-party scheduling without manual triage.

### AI Cloud Cost Whisperer

An AI-driven FinOps platform that delivers end-to-end visibility into AWS spend and translates anomalous billing events into plain-English root-cause narratives with actionable remediation paths. Architected around the AWS Cost Explorer API under a least-privilege IAM posture, with automated nightly ingestion via scheduled cron workflows and longitudinal cost history persisted in MongoDB Atlas. Containerised with Docker and shipped through a GitHub Actions CI/CD pipeline.
